=== The nuance you must not lose

* The library has three parse modes. `parse_json` with `JsonMode::Strict` or
  `JsonMode::Canonical` rejects duplicate keys. `JsonMode::Loose` goes through
  `serde_json` and keeps the last duplicate *silently*. A caller that links
  the library and wants I-JSON must use Strict or Canonical, never Loose.
* Before commit `0fdeea7`, `parse_json` had no strict path. Older checkouts,
  including the commit before `0fdeea7`, accept duplicate keys.
* This file checks behaviour on a handful of controls. It does not claim
  conformance with every RFC 8785 number-serialisation case.
